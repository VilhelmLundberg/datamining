# datamining
BGG datamining  - Cluster users to see what people have for tendencies.

## Project structure

- `data/` - place raw and processed datasets here.
- `scripts/data_cleaner.py` - data cleaning steps.
- `scripts/heatmap.py` - heatmap generation logic.
- `scripts/feature_engineering.py` - feature creation logic.
- `scripts/clustering.py` - clustering workflow logic.
